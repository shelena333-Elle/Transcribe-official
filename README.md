# Transcribe — локальный транскрибатор

Локальный транскрибатор на базе [Whisper](https://github.com/openai/whisper) (через [faster-whisper](https://github.com/SYSTRAN/faster-whisper)).  
Работает **на вашем компьютере**, бесплатно, без облачных API.

## Возможности

- Загрузка аудио: MP3, WAV, M4A
- Drag & drop или выбор файла
- Автоматическая нарезка длинных записей (по 20 минут)
- Фоновая обработка — можно закрыть браузер
- Готовый текст сохраняется в папку `results/`
- **Структурирование**: спикеры по именам, абзацы-реплики, тематические блоки с заголовками
- Режимы **Быстрее** (`tiny`) / **Точнее** (`base`) — в памяти одна модель
- Кнопка **Стоп / Удалить** — отмена отправки, остановка обработки, сброс очереди
- При Стоп сохраняется **частичный** уже распознанный текст
- **Очередь файлов** (по одному, без параллельной нагрузки)
- **Плеер** для прослушивания перед стартом
- **История** из папки `results` и кнопка **Очистить кэш** (папка `jobs`)
- Экспорт: копирование, **TXT**, **Word (DOCX)**, **PDF**

## Требования

- Windows 10/11
- Python 3.10+
- FFmpeg

## Установка

### 1. Python

Скачайте с [python.org](https://www.python.org/downloads/) и при установке отметьте **Add python.exe to PATH**.

Или через winget:

```powershell
winget install Python.Python.3.12
```

### 2. FFmpeg

```powershell
winget install Gyan.FFmpeg
```

### 3. Зависимости проекта

```powershell
cd путь\к\папке\проекта
python -m pip install -r requirements.txt
```

При первом запуске Whisper скачает модель (~150 МБ для `base`).

## Запуск

Дважды кликните **`start.bat`** или выполните:

```powershell
python server.py
```

Откройте в браузере: **http://127.0.0.1:5000**

> Страницу нужно открывать через сервер (`start.bat`), а не двойным кликом по `index.html`.

## Как пользоваться

1. Запустите `start.bat` (не закрывайте чёрное окно).
2. Выберите или перетащите аудиофайл.
3. Выберите режим: **Быстрее** или **Точнее**.
4. Нажмите **«Начать транскрибацию»**.
5. Укажите число собеседников и их имена (например: `Анна, Иван`).
6. Нажмите **«Структурировать текст»** — появятся реплики и тематические блоки.
7. Выгрузите результат в TXT / Word / PDF.

## Структурирование

Алгоритм работает локально, без облака:

1. Сегменты Whisper склеиваются в реплики по паузам.
2. Смена спикера определяется по длинной паузе / завершённой фразе (удобно для интервью и диалогов).
3. Тематические блоки режутся по времени; заголовок строится по ключевым словам блока.

Имена спикеров можно править вручную в поле — после повторного структурирования подписи обновятся.  
Структурированный текст также сохраняется в `results/`.

> Это эвристика по паузам, а не нейросеть-диаризация. Для сложных совещаний с перекрывающейся речью качество ниже — см. идеи улучшений ниже.

## Настройки (необязательно)

Перед запуском `start.bat` в командной строке:

```powershell
# Более быстрая модель (чуть хуже качество)
set WHISPER_MODEL=tiny

# Размер части при нарезке (в секундах, по умолчанию 1200 = 20 мин)
set CHUNK_SECONDS=900
```

## Структура проекта

```

├── index.html       # Страница приложения
├── app.js           # Логика браузера

├── start.bat
├── results/         # Готовые тексты
└── jobs/            # Временные файлы
```

## Ориентиры по времени (модель base, CPU)

| Длина аудио | Примерное время |
|-------------|-----------------|
| 5 мин       | 3–10 мин        |
| 30 мин      | 20–45 мин       |
| 100 мин     | 1,5–3 ч         |

## Безопасность и приватность

- Аудио обрабатывается **только на вашем ПК**
- Данные **не отправляются** в облако
- Папку `results/` не добавляйте в git — там личные тексты
